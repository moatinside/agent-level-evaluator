# Phase 2.2 実行計画: 新規性スコアリング

## 目的

新しいアイデアと過去の実験結果の意味的重複を測定し、既存アイデアと新規アイデアを機械的に分離する。

## 実験対象

依存ゼロで再現できる最小基準として、正規化した単語集合のJaccard類似度を使う。
既存アイデア群との最大類似度を求め、`novelty = 1 - max_similarity` とする。

これは汎用意味理解ではなく、Phase 2.2の実装・検証経路を確立するためのベースラインである。

## 実行

```bash
python3 scripts/run_phase_2_2.py --output execution-evidence/2.2/latest.json
```

## 合格条件

- 既存アイデアに近いケースと、異なるケースを入力する
- 類似ケースの新規性スコアが低くなる
- 非類似ケースの新規性スコアが高くなる
- 事前に定義したラベルとの一致率が80%以上になる
- 入力、類似度、新規性スコア、判定、実行条件をJSON保存する
- 同じ入力を再実行すると同じ結果になる

## 限界

単語集合のJaccard類似度は意味の同義語までは扱わない。
本実装は決定的ベースラインであり、将来のembedding等による意味類似度実装の比較対象とする。
