# Phase 2.1 実行計画: 進化的コード探索

## 目的

コード候補を複数世代にわたって生成・評価・選抜し、初期解と同じ予算のランダム探索を上回ることを再現可能に検証する。

## 実験対象

候補コードは、固定された二次関数の係数を持つPython関数として表現する。
評価対象は固定データ上のターゲット関数との二乗誤差で、誤差が小さいほど高スコアとする。

## 実行

```bash
python3 scripts/run_phase_2_1.py --seed 42 --generations 12 --population 24
```

## 探索手順

1. 固定seedで初期候補を生成
2. 候補コードを評価
3. 上位候補を選抜
4. 係数を変異させて次世代を生成
5. 12世代繰り返す
6. 同じ候補評価回数でランダム探索を実行
7. 結果をJSONで保存

## 合格条件

- 複数世代（12世代）が完走する
- 進化探索の最終スコアが初期スコアを上回る
- 進化探索の最終スコアが同予算のランダム探索を上回る
- 初期候補・最終候補・世代別スコア・比較結果を保存する
- seedと実行条件が保存され、同じコマンドで再実行できる

## 証拠

`execution-evidence/2.1/` 以下に、実行日時付きJSONを保存する。

## 失敗時

合格条件を1つでも満たさない場合、`status`を`failed`として保存し、`CHECKPOINTS.md`は更新しない。
